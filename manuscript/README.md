# Manuscript snapshot

This directory contains the exact manuscript and supplementary-material sources
and rendered PDFs associated with release v1.0.5. The PDFs are the files to use
for content review; LaTeX sources are included for transparency.

Figures used by these sources are in `figures/`, including Supplementary Figure
S8 for the v1.0.5 nested-validation, structure-quality and abundance-defined
null analyses. No editable third-party artwork or raw patient-level data are
included.
